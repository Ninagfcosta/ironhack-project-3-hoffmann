**Student:** Janaina Hoffmann (Nina)
**Lab:** Audit your teammate's project — GDPR lens

## What's in this repository

| File | What it is |
|---|---|
| `gdpr-audit-marc-project.md` | My full GDPR audit of my teammate Marc's project (VR Competitive Intelligence Copilot) — data inventory, role map, lawful basis, risk analysis, law stacking, and final compliance memo |
| `system-brief-nina-simples.md` | The system brief of my own project (Company Research Bot), written so Marc could audit it back |

## Summary

- **Marc's project** processes personal data mainly through scraped online
  reviews (G2, Capterra, Trustpilot, Reddit) that sometimes include a
  reviewer's name or role. My audit found this needs a documented lawful
  basis, data processing agreements with vendors, and a retention limit
  before production use.
- **My project** (Company Research Bot) mostly deals with company facts, not
  personal data — the only personal data point is the Telegram user ID of
  whoever sends a message.
